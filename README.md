# 🔍 MoodLens — 60-Mood Text Detector

**MoodLens** is a lightweight text-analysis project that identifies possible emotions and moods from written text. It combines NLTK-inspired natural language processing techniques with custom mood lexicons to analyze text and detect up to 60 different moods.

## ✨ Features

- **60 Mood Detection:** Identifies a wide range of moods, from happiness and excitement to sadness, anxiety, frustration, and more.
- **Text Tokenization:** Breaks text into individual words for analysis.
- **Stop Word Detection:** Identifies common words that can be excluded from mood analysis.
- **Sentence Segmentation:** Separates text into individual sentences.
- **Mood Scoring:** Calculates weighted scores to identify the strongest mood.
- **Confidence Indicator:** Displays an estimated confidence percentage for the detected mood.
- **Keyword Highlighting:** Shows words that contributed to the mood detection.
- **Cleaned Text Output:** Displays meaningful words after stop-word filtering.
- **Interactive Interface:** Includes sample mood buttons and a simple text-analysis experience.

## 🧠 How It Works

1. The user enters a text message.
2. MoodLens tokenizes the text into individual words.
3. Common stop words are identified.
4. Meaningful words are compared against custom mood dictionaries.
5. Each matching word contributes to a weighted mood score.
6. The strongest matching mood is displayed with an emoji, description, and confidence estimate.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Natural.js
- Custom mood lexicons

## 🎯 Project Goal

The goal of MoodLens is to explore how natural language processing and keyword-based analysis can identify emotional patterns in written text through an interactive and accessible interface.

## ⚠️ Important Note

MoodLens uses keyword-based mood detection. Its results are estimates based on words and scoring rules, not a definitive understanding of someone's feelings
or a psychological diagnosis.
